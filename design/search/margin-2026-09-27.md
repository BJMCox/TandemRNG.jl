## Fixed matrix

Every probe runs F5, F6, F7, and F8 on discovery seed 42. Each index emits four
little-endian UInt32 words in tuple order, starting at index zero.

| Probe | Output at index i |
| --- | --- |
| `split_o_seq` | Exposed half of F_R(key, i, DOMAIN_SPLIT, 0) |
| `split_h_seq` | Hidden half of the same F input |
| `split_o_high` | Exposed half with counter swap32(i) |
| `split_h_high` | Hidden half with counter swap32(i) |
| `split_o_keybit0_xor` | Exposed halves XORed between key and key with bit 0 flipped |
| `split_h_keybit127_xor` | Hidden halves XORed between key and key with bit 127 flipped |
| `chunkstart_seq` | Exposed half of T(F_R(key, i, DOMAIN_STREAM, AUX_STREAM)) |
| `chunkstart_keybit0_xor` | Previous output XORed between key and key with bit 0 flipped |

`swap32(i) = ((i & 0xffffffff) << 32) | (i >> 32)` is bijective on UInt64.
It avoids repeating inputs after index 2^32. Key bits start at the low bit of
the first word. Both direct F8 halves match public split child keys. Chunk starts
retain the earlier diagnostic's extra step T. Seed whitening always uses F8.

The following seeds and raw keys were fixed before new output. The two reserved
seeds were drawn from Julia's RandomDevice.

| Role | Seed, hex | F8-whitened raw key words, hex |
| --- | --- | --- |
| Discovery | `000000000000002a` | `421d21eb 32d31777 62e7564b df2bdf82` |
| Replication A | `25ddc9d20ab7cb4b` | `e3c046b2 fe6b5c1f aab37a26 b9f4e6fa` |
| Replication B | `9f2c4624a9689212` | `b3c752d8 00b3a24a 2a81ec94 35eea24b` |

Any suspicious or FAIL discovery label triggers the same probe at all four round
counts on both reserved keys, with the same 256 GiB cap. Unusual labels do not
trigger replication. The protocol adds no adaptive seeds or depths and does not
require F7 to fail.

Five probes trigger: `chunkstart_seq`, `split_h_high`, `split_h_seq`,
`split_o_high`, and `split_o_keybit0_xor`. These produce the 40 replication runs.

PractRand 0.96 uses:

```text
stdin32 -tlmin 20 -tlmax 38 -tf 1 -te 0 -multithreaded -a -tlmaxonly
```

The fixed-length wrapper appends `-tlmaxonly`, so flags do not stop a run before
its byte cap. Infrastructure errors stop the affected worker and preserve its
partial attempt. The executable SHA-256 is
`e771559e82e935df5a111a64537e7c3173467c0d32f5769eea4701ca7629481b`.
