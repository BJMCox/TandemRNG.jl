# Public performance and result-type coverage, 2026-09-26

Measurements use AMD EPYC 7702P and NVIDIA A100-PCIE-40GB with Julia 1.13.0.
The host was idle before the runs. CPU boost remained enabled. Local macOS timings
were not used because the host was not reliably idle.

The frozen baseline is `eef77ac4a6f43d7027ccf6e4c18ff049c80fa8da`.
PureRNGs is `a282e4fa4e064dfe1db29673a8fc811db8caef26`; Random123 is 1.7.1.
The public [runner](../../benchmark/README.md) records source hashes, manifests,
configuration, raw timings, and completion status. All three modes completed.
The retained directories are `public-candidate-cpu`, `public-candidate-gpu`, and
`public-candidate-latency`. Source snapshots and detailed logs remain outside Git.

Scalar improvements use native Julia: inline bridge forwarding, a simpler scalar
cache transition, and fixed choices for 64-bit extraction. Fixed extraction for smaller
integers reduced performance for several types in exploratory measurements, so those types
retain their indexed path.
The stream, recurrence, and constants remain unchanged.

CPU chains cover all 18 result types. Fills compare Float64, Float32, UInt32, and Bool.
Every scalar chain covers at least 1,024 draws and two K32 groups. Type arguments use
`Val` inside the timing harness to avoid runtime type dispatch and boxing.
The reported ranges contain the per-pass minima and are not confidence intervals.
Random123 supplies 23/52 random bits through the measured Float32/Float64 sampler
paths; the other references supply 24/53. Core, scalar, and fill rates measure different work.

## Later CPU fill tuning

Contiguous complex arrays now use the same vector stores as their real components.
Float16 row conversion uses native Julia UInt32 vectors, an exact exponent-bias
adjustment, and the existing transpose. All 65,536 half-word inputs pass an independent
Float16 mapping oracle. GPU conversion code remains unchanged.

Single-task checks over 2^20 elements give the following destination rates.
These follow-up checks are separate from the three-pass public runs above.

| Type | Initial GiB/s | Final GiB/s |
| --- | ---: | ---: |
| Float16 | 2.18 | 4.59 |
| ComplexF16 | 2.07 | 4.58 |
| ComplexF32 | 4.24 | 10.63 |
| ComplexF64 | 5.80 | 7.63 |

All 18 final single-task fill checks allocate zero bytes. The native Float16 conversion
without explicit bit encoding reached 3.78 GiB/s in the exploratory measurement within the same process, below the
selected 4.59 GiB/s encoding. The source snapshots distinguish these later fill changes
from the preceding scalar, GPU, and startup measurements.

## Conformance

- CPU: 4,214 tests pass on macOS Julia 1.13.0 and 1.10.12, and EPYC Linux Julia 1.13.0,
  including Aqua and independent mappings.
- PureRNGs: 72 type checks and 15 bridge checks pass.
- CUDA: 358 checks pass, including all 16 supported native and bridge kernel scalar types.
- Metal: 337 fill and residence checks pass over its 14 supported types.
- Reactant: 133 native checks and 16 bridge checks pass over supported traced operations.
- JET and inference: 90 checks pass across all 18 native and bridge scalar types, with zero allocations.
- CLI: eight checks cover invalid input, existing output paths, and retained failed-run records.
- Documentation: the local build and its doctest pass without deployment.

The final CPU-only fill changes retain the GPU mappings used by the device checks.
AMDGPU hardware validation remains deferred. No GitHub CI runs were requested.
